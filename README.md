# dsh-whale-opening

单窗口开屏插件 0.3.1。动画只占主窗口内容区，保留原生标题栏和窗口按钮，无子窗口、无侧栏页面。

## 内容
本包只有配置、Host/Client 入口、本文档、许可、视频及其第一帧，共8个文件。无历史版本、备份、原生子窗口脚本或开发测试资源。

## 行为
- 首帧遮罩先于主界面显示；视频从主窗口放行后开始播放。
- 真实界面在隐藏状态截图，裁掉标题栏，后半段使用此启动快照；仅内存保存，不上传。
- 缩放/调整窗口后快照失配时回退展示页。
- 宿主启动不等待插件动画，避免循环等待；窗口显示单独等待动画就绪，超时安全跳过且不迟到补播。
- Esc跳过；尊重系统减少动态效果设置。
- 桌面按本次进程启动握手播放，不使用浏览器旧播放标记；浏览器每标签页会话播放一次。

## 安装

### 从 GitHub 安装（网页覆盖层模式）
```bash
dsh plugin add github:RealGyx/dsh-whale-opening
```
多 profile 时用 `dsh plugin --profile <profile名> add github:RealGyx/dsh-whale-opening`；同一 spec 也可填入插件管理器的包名输入框。安装器会先用 `git ls-remote` 探活仓库（默认 5 秒超时），再由 pnpm 下载并写入 profile 清单，最后自动启用。

- **前置**：`pnpm` 与 `git` 在 PATH 上；包内含约 35 MB 视频，首次安装需下载整包。
- **版本要求**：`engines.dsh` 为 `>=0.2.0-rc.1 <0.3.0`。版本不符会以 `incompatible-version` 拒绝，可用 `dsh plugin allow-version` 或插件管理器授予豁免后重试。
- **更新**：用同一 spec 再执行一次 `add`。
- **卸载**：`dsh plugin remove dsh-whale-opening`。

### 两种安装形态的效果差异
| 安装方式 | 开屏时机 | 播放次数 | 后半段画面 |
|---|---|---|---|
| 仅装本仓库的插件本体 | 界面加载完成后覆盖上来，非首屏遮罩 | 浏览器每标签页会话一次 | 展示页 |
| 配套桌面集成 | 主窗口放行后的首屏遮罩 | 按本次进程启动握手 | 真实界面快照 |

### 桌面集成不在本仓库
配套桌面集成由工作区唯一的 `安装开屏.cmd` 安装，运行前校验文件，自动退出/重开 DSH，不创建备份，不修改插件启用设置。它改写 DSH 自身的 `desktop.asar`（Electron main 与 preload）以暴露 `window.dshDesktop.opening` 桥，并对单一具体构建做哈希锁定与路径绑定，版本变化即拒绝覆盖。因此该补丁不随本仓库分发；仅安装本插件本体时，行为见上表第一行。

桌面集成绑定当前 DSH 版本；DSH 升级后应重新构建校验，不盲目覆盖不同版本。
