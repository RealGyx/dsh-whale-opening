# dsh-whale-opening

单窗口开屏插件 0.3.1。动画只占主窗口内容区，保留原生标题栏和窗口按钮，无子窗口、无侧栏页面。

## 内容
本包只有配置、Host/Client 入口、本文档、视频及其第一帧，共7个文件。无历史版本、备份、原生子窗口脚本或开发测试资源。

## 行为
- 首帧遮罩先于主界面显示；视频从主窗口放行后开始播放。
- 真实界面在隐藏状态截图，裁掉标题栏，后半段使用此启动快照；仅内存保存，不上传。
- 缩放/调整窗口后快照失配时回退展示页。
- 宿主启动不等待插件动画，避免循环等待；窗口显示单独等待动画就绪，超时安全跳过且不迟到补播。
- Esc跳过；尊重系统减少动态效果设置。
- 桌面按本次进程启动握手播放，不使用浏览器旧播放标记；浏览器每标签页会话播放一次。

## 安装
配套桌面集成由工作区唯一的 `安装开屏.cmd` 安装，运行前校验文件，自动退出/重开 DSH，不创建备份，不修改插件启用设置。仅安装本插件目录到浏览器环境时使用普通页面覆盖层，不能承诺插件加载前的首屏遮罩。

桌面集成绑定当前 DSH 版本；DSH升级后应重新构建校验，不盲目覆盖不同版本。
